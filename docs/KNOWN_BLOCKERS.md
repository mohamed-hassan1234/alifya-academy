## Developer-environment caveat

`npm run db:dev` (mongodb-memory-server with a data folder) **lost its data** after the process was terminated uncleanly at the end of a session (exit code 4). Treat it as disposable test infrastructure only. For anything worth keeping, use a real MongoDB replica set or Atlas.
